### SWHR2-R-0033 · Add item with a supplied quantity

#### SWHR2-R-0033.01 · Item not yet in the cart
- **SWHR2-C-0080** (unit, draft, v1) Adding EST-1 with quantity 5 to a cart without it creates a line with quantity 5
  - Preconditions: An empty cart, or one holding only EST-2 x 1.
  - Step 1: Add item EST-1 with quantity 5.
  - Step 2: List the cart lines.
  - Expected: The cart has a line for EST-1 with quantity 5, and any line that was already there is unchanged.

#### SWHR2-R-0033.02 · Item already in the cart
- **SWHR2-C-0081** (unit, draft, v1) Adding EST-1 with quantity 2 when it is already in the cart with 3 sets that line's quantity to 2
  - Preconditions: A cart holding EST-1 x 3.
  - Step 1: Add item EST-1 with quantity 2.
  - Step 2: List the cart lines.
  - Expected: There is exactly one EST-1 line and its quantity is 2: the supplied quantity replaces the old one and is not added to it (so not 5).

### SWHR2-R-0116 · Failure routing to an error page

  - Step 1: Raise the item-not-found failure from a request handler that goes through the error routing.
  - Step 2: Read the page that is returned.
  - Expected: The general catalog failure's error page is returned.

#### SWHR2-R-0116.03 · Unmapped failure
- **SWHR2-C-0092** (integration, approved, v1) A failure with no mapping for itself or any kind it belongs to gives a general server error
  - Preconditions: A test route that raises a failure type with no error-page mapping for it or any kind it belongs to.

  - Expected: The response is a general server error (HTTP 500) and not one of the mapped error pages.
