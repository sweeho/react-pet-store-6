### SWHR2-R-0025 · Per-item breakdown within a category

#### SWHR2-R-0025.01 · Category named in the request
- **SWHR2-C-0001** (integration, approved, v1) Revenue request naming category FISH returns per-item revenue for FISH items only
  - Preconditions: Database seeded with orders dated within 01/01/2001–12/31/2002 containing line items EST-1 (FISH, 2 × 10.00), EST-2 (FISH, 1 × 15.00) and EST-6 (DOGS, 3 × 20.00).
  - Step 1: Call the revenue report endpoint with start 01/01/2001, end 12/31/2002 and category FISH.
  - Step 2: Read the response body.
  - Expected: The response contains exactly two entries keyed by item: EST-1 = 20.00 and EST-2 = 15.00; no entry for EST-6 or any other category's item.

#### SWHR2-R-0025.02 · No category named
- **SWHR2-C-0002** (integration, approved, v1) Revenue request with no category returns revenue per category
  - Preconditions: Same seed as the FISH per-item case: EST-1 (FISH, 20.00), EST-2 (FISH, 15.00), EST-6 (DOGS, 60.00), all in range.
  - Step 1: Call the revenue report endpoint with start 01/01/2001, end 12/31/2002 and no category parameter.
  - Step 2: Read the response body.
  - Expected: The response is keyed by category: FISH = 35.00 and DOGS = 60.00; no per-item keys (EST-1, EST-2, EST-6) appear.
